## Estructura creada

### Frontend (`frontend/`)
- `app/page.tsx` — Home con cards de módulos
- `app/hype-cycle/page.tsx` — Página principal de análisis Hype Cycle
- `app/history/page.tsx` — Historial con filtros por categoría
- `app/categories/page.tsx` — CRUD de categorías
- `app/layout.tsx` — Layout global con sidebar
- `app/providers.tsx` — React Query provider
- `components/layout/Sidebar.tsx` — Navegación lateral
- `components/query-builder/QueryBuilder.tsx` — Constructor de búsqueda (replica la UI del master)
- `components/charts/HypeCycleChart.tsx` — Gráfica Plotly.js del Hype Cycle
- `components/charts/MentionsTimelineChart.tsx` — Barra de menciones por año
- `components/ui/AnalysisProgressBar.tsx` — Barra de progreso SSE
- `components/ui/MetricCard.tsx` — Tarjetas de métricas
- `lib/api.ts` — Cliente HTTP + SSE helper
- `store/analysisStore.ts` — Estado global (Zustand)
- `types/index.ts` — Tipos TypeScript (espejo de los modelos Python del master)

### Backend (`backend/`)
- `main.py` — FastAPI app con CORS
- `api/routes/hype_cycle.py` — POST /analyze, GET /history, GET /queries/{id}
- `api/routes/tasks.py` — GET /tasks/{id}/stream (SSE)
- `api/routes/categories.py` — CRUD categorías
- `requirements.txt` — Dependencias backend
- `.env.example` — Template de variables de entorno
