# Sesión 02 — Storage layer + mejoras visuales
**Fecha:** 2026-03-11
**Rama:** `feature/nextjs-migration`

## Lo que se hizo

### Backend — Storage layer migrado
1. Creado `backend/storage/__init__.py`
2. Creado `backend/storage/dynamodb.py` — `DynamoDBStorage` portado desde `src/data_storage.py`
   - Sin dependencias de Streamlit (st.* reemplazado por logging + raise)
   - Métodos: `put_analysis`, `put_analysis_raw`, `get_analysis_by_id`, `get_analyses_by_category`, `get_all_analyses`, `delete_analysis`, CRUD de categorías
   - Singleton `get_db()` para usar como FastAPI dependency
3. Creado `backend/storage/hype_cycle.py` — `HypeCycleStorage` portado desde `src/hype_cycle_storage.py`
   - Cache TTL en memoria (5 min), sin `st.cache_data`
   - Métodos: `save_query`, `get_queries(category_id?)`, `get_query_by_id`
4. Creado `backend/core/__init__.py`
5. Creado `backend/core/categories.py` — `CategoryService` sobre DynamoDBStorage

### Backend — Endpoints conectados a DynamoDB real
6. Actualizado `backend/api/routes/hype_cycle.py`
   - `GET /history` ahora usa `HypeCycleStorage.get_queries()` via FastAPI Depends
   - `GET /queries/{id}` ahora usa `HypeCycleStorage.get_query_by_id()`
7. Actualizado `backend/api/routes/categories.py`
   - `GET /` → `CategoryService.list_categories()`
   - `POST /` → `CategoryService.create_category()`
   - `PATCH /{id}` → `CategoryService.update_category()` (nuevo endpoint)
   - `DELETE /{id}` → `CategoryService.delete_category()`
   - `GET /{id}/usage` → `CategoryService.usage_count()` (nuevo endpoint)

### Frontend — Mejoras visuales
8. `frontend/app/layout.tsx` — Inter carga con pesos 400–800 y `display: swap`
9. `frontend/app/globals.css`
   - `font-feature-settings: "cv02","cv03","cv04","cv11"` en body
   - `font-variant-numeric: tabular-nums` para métricas
   - Nuevas clases: `.page-title`, `.metric-value`, `.heading-glow`, `.stat-num`, `.divider`, `.hover-lift`
   - Gradiente texto más rico (4 stops, azul→índigo→violeta→cyan)
   - Mesh-bg con más profundidad
10. `frontend/app/page.tsx` — hero h1 más grande (56px), heading-glow, stat cards usan `.stat-num`
11. `frontend/components/layout/Sidebar.tsx` — wordmark mejorado, fix unused import `BarChart3`
